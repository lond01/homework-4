# Завдання 3 — Середній бал студента

## Опис

Програма містить функцію, яка приймає ім'я студента та необмежену кількість його оцінок.

Функція обчислює та виводить середній бал студента.

## Код

```python
def student_grade(name, *grades):
    average = sum(grades) / len(grades)
    print(f"Студент: {name}")
    print(f"Середній бал: {average}")


student_grade("Саша", 10, 11, 9, 12, 10)
```

## Результат

```text
Студент: Саша
Середній бал: 10.4
```

## Що використано

* Функції `def`
* Необмежена кількість аргументів `*args`
* `sum()` — сума оцінок
* `len()` — кількість оцінок
* Ділення для обчислення середнього значення
